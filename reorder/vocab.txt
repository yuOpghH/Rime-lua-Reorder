# reorder/vocab.txt — 詞彙清單（UTF-8，TAB 分隔，記事本可直接編輯）
# 欄位：漢字	編碼	權重	類型	時間
# 前 3 欄與 Rime custom_phrase.txt 相同（詞、碼、權重），可整份貼入。
# 權重是普通數字（5、2.45、-1.2、50656 等），照原值存、照原值排序；+-5 為硬鎖。
# 編碼可寫「方案:碼」指定方案；沒有前綴時套用到目前作用中的方案。
# 類型（固頂／調頻／新詞）可留空；時間（YYYY-MM-DD HH:MM）可留空。
# 只有工具自己新建的詞會寫入類型與當前時間；貼上的列保持原樣。
# 空行與 # 開頭的行會被忽略；壞行會跳過並在左下回饋區標示行號，不會改寫本檔。
